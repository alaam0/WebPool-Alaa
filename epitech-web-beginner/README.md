# Epitech Web Bootcamp – beginner solutions

This workspace contains beginner-style solutions for the supplied Day 02–Day 10 PDFs and mini-project.

## Open in VS Code
1. Extract this ZIP.
2. Open the `epitech-web-beginner` folder in VS Code.
3. For HTML/CSS/JS, open the relevant `dayXX` folder and use Live Server (or open the HTML file in a browser).
4. For JavaScript modules, install Node.js and run `node task01.mjs` etc. (small tester files are included).
5. For PHP, install PHP. Run `php filename.php` for basic tasks. For web tasks use `php -S 127.0.0.1:8000` from the relevant folder.
6. Day 10 requires PHP with PDO SQLite enabled.

## Important notes
- The code is intentionally straightforward: simple variables, loops, conditions and functions, with comments where useful.
- Day 02 Task 09 refers to a visual mockup that is not readable in the supplied PDF text, so a simple decorative CSS layout is included.
- Day 03 Task 05 uses placeholder portfolio images and example contact details. Replace them with your own.
- Day 07 Tasks 01–07 use the exact provided starter HTML files copied from the archive.
- Day 10's supplied SQLite database is copied into the project. The PHP scripts expect it at `data/ajax_products.db`.
- Check the output yourself and make sure you can explain each function before submitting it.

## Code formatting

The HTML, CSS, JavaScript, PHP, and JSON files have been reformatted with indentation and line breaks to make them easier to read. Formatting is intended to preserve the existing exercise logic.
